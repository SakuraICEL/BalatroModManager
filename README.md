# Balatro Mod Manager · 小丑牌 Mod 管理器

## 项目介绍

一个面向 Windows 的小丑牌（Balatro）Mod 管理工具，方便浏览、下载和管理 Mod。

- 浏览 Thunderstore、GitHub 和社区精选清单，支持添加自定义 GitHub 仓库。
- 在卡片与列表视图间切换，通过搜索、分类、排序和收藏快速找到 Mod。
- 查看版本、更新时间、来源、下载量或星标，以及来源提供的依赖信息。
- 查看 Mod 介绍，支持中文机器翻译与原文切换。
- 管理本地 Mod 的安装、启用、禁用、卸载和更新检查。
- 查看环境检测报告和游戏日志，备份与恢复存档。

## 使用方法

1. 从本仓库的 **Releases** 下载程序包，解压后双击 `BalatroModManager.exe`。
2. 在“设置与备份”中确认游戏目录。如果未能自动识别，请手动选择，并先备份存档。
3. 打开“发现 Mod”，选择来源，使用搜索、分类或排序浏览。点击卡片或列表项查看详情，按需翻译介绍。
4. 选中需要的 Mod，点击“安装选中”或“安装 + 依赖”。也可在“已安装”页面选择本地 `.zip` 或 `.lua` 文件安装。
5. 在“已安装”页面管理启用状态、卸载或检查更新。安装及启用状态变更后，重启游戏使其生效。
6. 如遇到加载问题，可先查看“环境检测”和“游戏日志”。

需要添加自定义来源时，点击“管理来源”，每行填写一个 GitHub 仓库链接或 `owner/repo`，保存后即可浏览。

## 注意事项

- **本项目使用了 AI 辅助开发，仍可能存在未发现的错误、兼容性问题或不完善的功能。请谨慎使用；遇到问题欢迎在 Issues 中反馈。**
- 安装、更新、卸载 Mod 或恢复存档前，建议备份存档和重要的 Mod 文件。修改 Mod 时请先关闭游戏。
- 首次使用 Mod 前，请确认游戏所需的 Lovely、Steamodded 等加载环境已经正确安装；本工具不能保证所有 Mod 彼此兼容。
- “安装 + 依赖”依赖来源提供的信息。GitHub 等来源可能缺少依赖声明，请同时查看 Mod 原始说明，确认所需版本与依赖。
- 中文介绍为机器翻译，可能存在误译，安装要求和重要说明请以原文为准。
- 在线浏览、下载及翻译需要联网，可能受网络状况、接口限流或上游服务变化影响。翻译会将介绍文本发送至所选翻译服务。
- 第三方 Mod 的内容和安全性由其作者负责，请确认来源可信后再安装。
- 反馈问题时，请检查日志、诊断报告和截图，隐藏用户名、个人路径及其他私人信息。
